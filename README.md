================================================================================
                        GROUP PORTAL (DJANGO PROJECT)
================================================================================

ОПИС ПРОЄКТУ
------------
Group Portal — це багатофункціональний вебпортал для організації навчального 
та командного процесу, розроблений на фреймворку Django. Система об'єднує 
модулі для обміну інформацією, планування заходів, обговорень та ведення 
власного портфоліо.

ОСНОВНИЙ ФУНКЦІОНАЛ ТА МОДУЛІ
-----------------------------
Проєкт складається з таких застосунків (apps):
1. accounts / authentif — реєстрація, авторизація та керування профілями 
   користувачів (вхід, стартова сторінка).
2. announcements — створення та перегляд важливих оголошень.
3. materials — база навчальних або робочих матеріалів (завантаження та 
   перегляд).
4. academics — облік академічної інформації та навчального процесу.
5. events — календар подій, планування, перегляд деталей та керування 
   заходами.
6. forum — тематичний форум для створення тем та обговорень.
7. gallery — фотогалерея проєкту.
8. portfolio — розділ для демонстрації робіт та досягнень.
9. polls & surveys — проведення швидких голосувань та детальних опитувань.

ТЕХНОЛОГІЇ ТА ВИМОГИ
--------------------
* Мова програмування: Python 3.13+
* Вебфреймворк: Django (>= 5.2, < 6.0)
* Робота із зображеннями: Pillow (>= 10.0)
* База даних: SQLite3 (db.sqlite3)

ІНСТРУКЦІЯ ІЗ ЗАПУСКУ
---------------------
1. Клонуйте репозиторій або розпакуйте архів з проєктом та перейдіть у 
   кореневу папку (де знаходиться файл manage.py):
   cd "group progect django"

2. Створіть та активуйте віртуальне середовище:
   * Для Windows:
     python -m venv .venv
     .venv\Scripts\activate
   * Для Linux / macOS:
     python3 -m venv .venv
     source .venv/bin/activate

3. Встановіть необхідні залежності:
   pip install -r requirements.txt

4. Застосуйте міграції бази даних:
   python manage.py migrate

5. (Опціонально) Створіть адміністратора для доступу до адмін-панелі:
   python manage.py createsuperuser

6. Запустіть локальний сервер розробки:
   python manage.py runserver

7. Відкрийте браузер та перейдіть за адресою:
   http://127.0.0.1:8000/
